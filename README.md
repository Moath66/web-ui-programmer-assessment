# Friend Search

A simple friend search application built with HTML, CSS, and JavaScript.

## Features

- Search friends by name
- Case-insensitive search
- Partial name matching
- Handles empty search input
- Displays a message when no friends are found
- Includes automated Jasmine tests

## Technologies

- HTML
- CSS
- JavaScript
- Jasmine
- Node.js

## Running the Project

Open `index.html` in a browser using a local development server such as Live Server.

## Running Tests

Install the dependencies:

```bash
npm install
```

Run the test suite:

```bash
npm test
```

Expected result:

```text
6 specs, 0 failures
```
